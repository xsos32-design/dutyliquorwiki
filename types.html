蘇格蘭單一麥芽威士忌

一家蒸餾廠、只用發芽大麥、壺式蒸餾，在蘇格蘭橡木桶裡至少放 3 年；每家酒廠都有自己的個性。

歷史HISTORY

  1. 1494蘇格蘭國庫紀錄第一次提到用麥芽做「生命之水 aqua vitae」，是威士忌最早的文字紀錄。
  2. 1823消費稅法降低合法蒸餾的門檻，很多私釀酒廠轉為合法（格蘭利威、麥卡倫都在 1824 年取得執照）。
  3. 1963格蘭菲迪率先把單一麥芽推到海外市場，開啟現代單一麥芽潮流。
  4. 2009新的蘇格蘭威士忌法規上路，五種分類與產區名稱正式寫進法律。

怎麼做出來HOW IT'S MADE

  1. 發麥：大麥泡水發芽，再烘乾（用泥煤烘就會有煙燻味）
  2. 糖化：磨碎加熱水，把澱粉變成麥汁
  3. 發酵：加酵母變成約 8% 的「酒醪」
  4. 蒸餾：銅製壺式蒸餾器蒸兩次（少數三次）
  5. 熟成：裝進橡木桶，在蘇格蘭至少 3 年
  6. 裝瓶：可加水調度數；只能加普通焦糖色，不能加糖或香料

Single Cask 單桶只用一個桶裝瓶，每桶味道不同
Cask Strength 原桶強度不加水稀釋，度數常 50–60%

優點與賣點WHY BUY

  • 最能喝出「酒廠個性」：同樣是威士忌，斯貝賽果香、艾雷島煙燻，差很多
  • 年份與桶型清楚，好比較、好往上推
  • 送禮與收藏價值高，高年份與限定款保值

怎麼喝純飲最能喝出差別；加一點點水會打開香氣；喜歡清爽可以做 Highball（威士忌加蘇打水）。

歷史HISTORY

  1. 1830連續式蒸餾器取得專利，可大量做出清淡的穀物威士忌。
  2. 1853Andrew Usher 推出最早的調和威士忌之一。
  3. 1860法律開放在保稅倉庫調和，調和威士忌開始大量生產。
  4. 1909起瓦士推出 25 年，高年份調和成為送禮主力。

怎麼做出來HOW IT'S MADE

  1. 各家酒廠做出麥芽威士忌與穀物威士忌
  2. 調酒師挑選數十種原酒
  3. 依配方調和，讓每批味道一樣
  4. 再放回桶裡「融合」一段時間後裝瓶

分類與等級GRADES

Blended Scotch 調和麥芽＋穀物，最常見
Blended Malt 調和麥芽只有麥芽、來自多家酒廠（例如三隻猴子）
年份瓶中最年輕原酒的年數
顏色或名稱分級例如約翰走路紅、黑、金、藍

優點與賣點WHY BUY

  • 好入口、味道穩定，任何人都不容易踩雷
  • 價格帶最廣，從平價到極高階
  • 品牌知名度最高，送禮安全

怎麼喝純飲、加冰、Highball 都適合；高年份建議純飲。
